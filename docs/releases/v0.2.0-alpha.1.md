# v0.2.0-alpha.1 — experimental developer preview

First public prerelease: foreground probe 0.1.10, an **inactive** background
module candidate and control UI, complete corresponding source, checksums and
build provenance. Linux/macOS sanitizer tests and archive safety checks gate
publication; Switch binaries are built by CI from the tagged public source.

## What is actually verified

An earlier deployed probe captured real K7Q3M7 keyboard/consumer notifications:
109 decoded reports, 34 press and 34 release edges across twelve named buttons,
on one first-generation Switch running Horizon 22.5.0. These newly rebuilt public
release binaries have **not themselves been tested on the console**.

The background module, virtual-controller HOME/menu input, cleanup and real
power behavior still need supervised hardware testing. Other remote models are
untested. Persistent bonding/automatic reconnect, remote wake and microphone
audio are **not supported/verified**. Voice is a button event only.

## Before downloading

This is **not a turnkey driver**. The custom passive MissionControl observer is
required; stock MissionControl does not expose the project's IPC. Its public
source/patch and pinned upstream dependencies are documented in the source zip;
no observer binary or unpublished BLE source is bundled.

The module zip has a `candidate/` prefix, no `boot2.flag`, no target-address
configuration and no automatic activation. Do not extract it as a live install.
`exefs.nsp` is a sysmodule container, not a game installer. Keep your working
configuration, backups and recovery route. Read the supervised test plan first.

The candidate rejects firmware other than 22.5.0 and unknown remote fingerprints,
requires explicit operator arming, and retains bounded capture/link/input limits.
Do not remove a persistent safety marker to retry without a confirmed physical
reboot and preserved diagnostics. A successful build does not prove safe pairing.

See `PROVENANCE.json` for the exact source commit and dependency/binary hashes.
`SHA256SUMS` covers the three zip assets and provenance file. No device logs,
console keys, firmware, games, private addresses or SDK archives are included.
