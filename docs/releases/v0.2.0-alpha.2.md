# v0.2.0-alpha.2 — background controller preflight

Progress toward a native-feeling Atmosphere background remote module. This is
still an **inactive, device-untested developer preview**, not a daily-use driver.

- Physical **Y** in the matching control UI requests one neutral virtual-pad
  attach/detach check while IDLE. It performs no Bluetooth initialization, scan,
  capture, pairing, link or target-file access. A successful check leaves IDLE
  for the later explicit A/ZL test; failure stops without retry.
- Status protocol **v2** shows controller-check result, sticky pad-cleanup error,
  last successfully acknowledged mapped mask and successful Set-reply count.
  Successful changed outputs are logged; unchanged mapped masks avoid extra IPC.
- A failed neutral write retains the last nonzero ACK. Cleanup failures are no
  longer hidden by a successful explicit Stop result. Local detached state and
  service ACKs are not proof of actual controller removal or visible navigation.
- Sanitizer tests now exercise the actual HDLS adapter through a minimal fake
  SDK, including owned aligned buffer, requests, failures and press/release.
  The background-module development plan documents bond/reconnect and power gates.

Use the alpha.2 module **and** control NRO together. Protocol-v1 commands/status
are rejected; do not mix the alpha.1 UI with the new module. The foreground
probe remains version0.1.10 with no transport change in this revision.

Background ARUID0 access, HDLS navigation/coexistence and PSC behavior remain
device-unverified. Persistent bonding/reconnect, true sleep wake and microphone
audio remain unsupported/unverified. Firmware is still limited to Horizon22.5.0.
The custom public MissionControl observer remains required for the BLE test and
is not bundled as a binary. The neutral-controller check alone does not use it.

No automatic activation, boot2 flag, target config or radio/paired-device change
is supplied. Read the updated supervised test plan and keep the working recovery
route and original probe/observer intact. Verify checksums and provenance; the
release's rebuilt binaries have not been device-tested.
